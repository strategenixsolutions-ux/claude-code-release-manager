# Activity Log

The detailed running record of changes to this shared workspace. `../CHANGELOG.md` holds the
one-entry-per-release summary; this file holds the depth: what was built, why, what was
tried, what was rejected, and anything a future reader needs to reconstruct a decision.

Newest first. Append during a release, or when something changes outside a release that
someone will need to know about later.

Entry shape:

```
## <YYYY-MM-DD> - <short title> (<release version, or "outside a release">)

**What changed.** The files, the paths, the shape (additive, overwrite, deletion).

**Why.** The problem, who raised it, the request ID or queue ID.

**How it was built and verified.** Staged location, hash pins, what was tested and how, what
the output was.

**Decisions and rejected options.** What else was considered and why it lost.

**Follow-ups.** Anything carried forward, with its own queue item if it needs one.
```
